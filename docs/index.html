Install

Full walk-through with silent-install flags: how to install Hamachi.

  1. Download hamachi.msi from secure.logmein.com.
  2. Verify the SHA-256 (above).
  3. Run the installer — administrator rights are required.
  4. Sign in with a LogMeIn account.
  5. Create a network, or join one with an ID and password.

Silent install

msiexec /i hamachi.msi /qn

Joining a network

Network IDs, gateway mode and troubleshooting: create or join a network.

  1. On the machine that will host: Network → Create new network, set an ID and password.
  2. On the second machine: Network → Join existing network, paste the ID, enter the password.
  3. Each peer receives a 25.x.x.x address — use it the way you would use a LAN IP.

Frequently asked questions

Is Hamachi free?

There is a free tier limited to 5 devices in a network. Paid plans raise the limit and enable gateway features.

Do I need a LogMeIn account?

Yes — an account is required to create or join networks.

Does it need port forwarding?

No. Connections are brokered through LogMeIn's relays, with direct peer-to-peer when NAT allows it.

Windows only?

LogMeIn also publishes macOS and Linux builds on the vendor site. This page covers the Windows MSI.
