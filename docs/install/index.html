How to install Hamachi on Windows

MSI installer, administrator rights, silent flags and the first launch.

Before you start

  • Administrator rights. The MSI writes to Program Files and registers a service.
  • Windows 10 / 11 / Server, x64. The vendor also ships macOS and Linux builds, but this page covers the Windows MSI.
  • A LogMeIn account. You cannot create or join a network without one.
  • The installer from the vendor CDN. secure.logmein.com/hamachi.msi — 14,761,984 bytes (14.1 MB).

Verify the file first

Compare the SHA-256 before running anything. The full procedure is on the checksum page, and the expected value is:

5c672c9a12b69b75b2cf25710bac8c579b3ef7ed1a907930dc0d7e20eab7584d  hamachi.msi

Step by step

  1. Download hamachi.msi from secure.logmein.com.
  2. Right-click the file → Install, or double-click it. Accept the elevation prompt.
  3. Follow the wizard. The default install location is fine for a single-user machine.
  4. Launch LogMeIn Hamachi from the Start menu.
  5. Sign in with your LogMeIn account, or create one.
  6. Create a network, or join one with an ID and password — see network setup.

After sign-in the client shows your machine with a 25.x.x.x address. That address is what peers use, exactly like a LAN IP.

Silent install

For a scripted roll-out across several machines:

msiexec /i hamachi.msi /qn
FlagEffect
/qnNo UI at all. Use /qb for a basic progress bar.
/norestartNever reboot automatically.
/l*v install.logVerbose log — the first thing to read when a silent install fails.
TARGETDIR="D:\Hamachi"Non-default install location.

Exit code 0 means success. 3010 means success but a reboot is pending. 1618 means another installation is already running — wait and retry. 1603 is a fatal error; the log above tells you which step failed.

Uninstall

Settings → Apps → Installed apps → LogMeIn Hamachi → Uninstall. From a command line: msiexec /x hamachi.msi /qn. Leave the network on the account first if other peers still depend on it.
