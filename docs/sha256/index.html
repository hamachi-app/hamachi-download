Verify the Hamachi installer

One hash, three commands, ten seconds — and you know the file is the vendor's build.

The expected value

For hamachi.msi as currently served by LogMeIn's CDN:

5c672c9a12b69b75b2cf25710bac8c579b3ef7ed1a907930dc0d7e20eab7584d  hamachi.msi

Size: 14,761,984 bytes (14.1 MB). Published: 2026-10-01 (vendor CDN Last-Modified).

PowerShell

Get-FileHash .\hamachi.msi -Algorithm SHA256

Command prompt

certutil -hashfile hamachi.msi SHA256

7-Zip

7z h -scrcsha256 hamachi.msi

Reading the result

Compare the hex string, not the file name. Hashes are case-insensitive. If your value differs:

  • the download was truncated or corrupted — download again;
  • the vendor published a new build — check the version history and compare the version in the file name;
  • the file came from somewhere other than secure.logmein.com — delete it and take it from the vendor.

Why this page does not host the installer

A re-hosted copy cannot be traced back to the vendor, and a checksum published next to a re-hosted file only proves that the re-host copied it faithfully. Every link here points at LogMeIn's own CDN, so the hash above always describes the file you are about to run.
