Create or join a Hamachi network

Two clicks on the host, an ID and a password on the guest.

Create a network

  1. Open the client and sign in.
  2. Network → Create new network.
  3. Choose a network ID and a password. The ID is public-ish — anyone who knows it and the password can join, so treat the password as the actual secret.
  4. The creating machine appears in the list with a 25.x.x.x address.

Join a network

  1. Network → Join existing network.
  2. Paste the network ID and enter the password.
  3. The peer appears in the list once it has authenticated.

Share the ID and password out of band. Do not paste them into a public chat — a network is only as private as its password.

Mesh or gateway

ModeWhat it doesPlan

When a peer does not appear

  • The other machine is offline, or signed in to a different LogMeIn account.
  • The network ID has a typo — the ID and the password are both case-sensitive.
  • A local firewall blocks the client's traffic. Allow it on private networks.
  • The peer shows as relayed rather than direct: it works, but expect higher latency. See how packets travel.

Check the link

From one peer, ping the other's 25.x.x.x address. A reply means the overlay is working and any remaining problem is in the application, not in the network. Then try the actual service — an SMB share or an RDP session — because ICMP and TCP can be treated differently by local firewalls.
