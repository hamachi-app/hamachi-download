Where the version number comes from

LogMeIn does not publish a version number on the download page and does not maintain a public changelog. The number above is read from the installer itself: the ProductVersion resource of EngineEXE_x64 inside hamachi.msi. That makes it checkable rather than assumed.

How this page stays current

  • The vendor CDN response headers (Last-Modified, content-length) are polled weekly.
  • When the installer changes, the version resource is re-read and this table, the download page and the checksum are updated together.
  • The release tag v2.4.0.79 carries SHA256SUMS.txt for the build it describes.

Most download pages in this niche sit on versions that are a year old. Keeping the number honest is the whole point of this page.
